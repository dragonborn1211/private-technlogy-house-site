# Private Technology House — сайт

> The deeper the engineering, the lighter the experience should feel.

Статический сайт без фреймворков и сборки: HTML, CSS и немного JavaScript.
Концепция бренда — в [`docs/CONCEPT.md`](docs/CONCEPT.md), исходный макет — `docs/reference/mockup.webp`.
Первоначальный однофайловый экспорт (картинки в base64) сохранён в истории, в первом коммите.

## Запуск

```bash
python3 -m http.server 8080
# или
npx serve .
```

Открыть http://localhost:8080. Через `file://` тоже работает, но метрики страницы будут неполными.

## Структура

```
index.html            разметка всех секций
assets/css/main.css   токены, секции, режим «Глубина», адаптив
assets/js/main.js     данные объектов и слоёв, интерактив, метрики, палитра
assets/img/           единственное фото — гора в «Стандарте» (WebP)
tools/build_hero.py   сборка кадра с девушкой (сейчас не используется, см. ниже)
docs/                 концепция, макет и исходник кадра с девушкой
```

## Что делает сайт IT-сайтом

Сайт сам — **Object №00**, доказательство компетенции. Сложность лежит под поверхностью и проявляется, только когда её зовут.

| Что | Где | Как устроено |
|---|---|---|
| **Глубина** — поверхность становится прозрачной | переключатель «Глубина» в шапке, клавиша `B`, объект `00` | Фото горы гаснет, проявляются 12-колоночная сетка, границы блоков с названием, технологией и реальным размером, и HUD с метриками страницы |
| **Живые метрики** | HUD в режиме «Глубина» и строка под принципом «Производительность — часть красоты» | `PerformanceObserver`: TTFB, FCP, LCP, CLS, вес и число запросов — измерено в браузере посетителя. Строка в «Стандарте» показывается, только если цифры хорошие |
| **Command palette** | `⌘K` / `Ctrl+K`, на телефоне — кнопка меню | Навигация и действия с поиском, стрелки, Enter, Esc |
| **Craft — слои системы** | секция 04 | CSS 3D-стопка из 7 стеклянных слоёв: выбранный слой светится, слои над ним поднимаются и становятся прозрачными. Рядом — реальный код слоя с подсветкой. Пока секция на экране, слои раскрываются сами |
| **Продукт и деплой** | первый экран | Тёмный «экран» с дашбордом продукта и терминал, который его выкатывает: `git push` печатается, шаги закрываются галочками. Всё на HTML и CSS |
| **Форма как запрос** | Enter | Под полями виден JSON будущего `POST /enter` |
| **BUILD-отпечаток** | футер | FNV-1a хеш страницы и `document.lastModified` |
| **Для любопытных** | исходник и консоль | Комментарий в начале `index.html` и сообщение в DevTools |
| **Блик на льду** | все стеклянные карточки | Блик бежит по кромке карточки за курсором (только мышь, без reduced motion) |

Дизайн — светлая «ледяная» система по референсу: молочный фон `#FAF8F4`, тёмно-синий текст `#0F1B24`, стальной акцент `#4F7184`, стеклянные карточки с тонкой обводкой в полпикселя, Cormorant Garamond для заголовков, Manrope для текста, JetBrains Mono для подписей. Изображения продукта (дашборд, терминал, превью объектов, слои и код) — тёмные экраны. Подвал тёмный, к нему ведёт плавный переход. Фон статичный, без анимации.

Всё учитывает `prefers-reduced-motion`. Контент виден и без JavaScript.

## Где править контент

- **Объекты** — массив `OBJ` в `assets/js/main.js` (имя, категория, описание, стек, `url` для строки адреса в превью). Миниатюры — `.thumb`, окна-превью — `.pv[data-preview="N"]` в `index.html`. Превью нарисованы на HTML и CSS, без картинок. Индекс `N` совпадает с порядком в `OBJ`.
- **Слои Craft** — массив `LAY` там же (заголовок, описание, стек, код).
- **Каналы связи** — объект `CONFIG` в начале `assets/js/main.js`:
  - `endpoint` — URL, принимающий `POST application/json { task, contact }`;
  - `email` — запасной канал через mailto;
  - `telegram` — username без `@`;
  - `github` — ссылка для футера.

  Пока всё пусто, форма честно отвечает «Канал связи ещё не подключён».
